# Portofolio Perancangan Database

Folder ini berisi kumpulan proyek dan tugas yang berkaitan dengan perancangan serta pengelolaan basis data.

## 1. Sistem Informasi Kasir Dracikan

### Deskripsi Proyek
Perancangan database untuk sistem informasi kasir pada usaha coffee shop Dracikan yang bertujuan membantu pengelolaan data produk dan pencatatan transaksi.

### Ruang Lingkup Pekerjaan
- Perancangan struktur database.
- Pembuatan Entity Relationship Diagram (ERD).
- Pembuatan Logical Record Structure (LRS).
- Perancangan relasi antar-tabel.
- Implementasi database menggunakan SQL.

### Tools yang Digunakan
- MySQL
- phpMyAdmin
- Laragon

### Status Proyek
Dokumentasi dan pengembangan portofolio.
